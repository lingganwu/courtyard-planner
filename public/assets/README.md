# 本地化图片资产目录

正式版本的植物、材料、构筑物和水景图片全部存放在此目录或其子目录，不直接热链第三方网站。

建议目录：
- `plants/trees/`
- `plants/shrubs/`
- `plants/perennials/`
- `plants/bamboo-vines/`
- `plants/aquatic-groundcover/`
- `materials/stone/`
- `materials/brick/`
- `materials/wood-composite/`
- `materials/metal-drainage/`
- `structures/`
- `water/`

每个资产都应在 `src/data/assets.json` 登记来源、许可、对应条目、图片类型和审核状态。
