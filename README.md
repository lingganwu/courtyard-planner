## ✨ 项目定位

**庭院设计百宝箱**希望把庭院设计中相互割裂的空间规划、植物配置、硬景材料、构造做法和工程造价，放进同一条可计算、可调整、可复核的工作流。

当前 `main` 是可运行基础版本；专业版正在 `rebuild/professional-toolbox` 分支持续重构。未完成能力不会在这里标成“已交付”。

## 🧭 专业版核心架构

### 01｜项目与场地

城市/区域、气候区、庭院面积、朝向日照、预算档位、设计风格、毛坯/翻新以及大乔木进场和吊装条件。

### 02｜动态空间配比

绿化、硬质铺装、水景及构筑物支持独立开关和动态调整，总面积严格闭合，并继续联动苗木、材料和 BOQ 工程量。

### 03｜专业植物选品

主画布只展示当前方案已选植物，候选植物进入选品抽屉筛选：

- **植物分类**：常绿乔木、落叶乔木、庭院观果树、灌木球类、花境、观赏草、竹类、藤本、水生湿生、草坪地被、阴生蕨类与苔藓
- **观赏属性**：观花、观叶、观果、观姿观干、芳香、综合
- **季相条件**：春、夏、秋、冬及具体月份
- **生态条件**：日照、水湿、耐寒、耐热等

正式植物数据将关联中文名、拉丁学名、工程规格、建议密度、季相、价格构成和经过审核的本地图片。

### 04｜硬景材料与工程构造

逐步覆盖天然石材、景观砖、透水材料、木竹与合成材料、生态铺装、金属收边、排水、墙面饰面和庭院构筑物。

每个正式条目将包含规格工艺、本地实景图、损耗率、构造断面、工料机拆解和 BOQ 联动。

### 05｜景观小品与水系

廊架、景墙、景观置石、庭院鱼池及过滤系统等作为独立工程模块选配，与规格、工法和造价清单关联。

### 06｜可追溯造价

不采用无法解释来源的“网络参考价”。

**硬景综合单价** = 主材 + 基层/辅材 + 人工 + 机械 + 物流 + 损耗 + 措施

**苗木综合单价** = 苗木采购 + 土球包装 + 运输 + 种植土改良 + 人工/吊装 + 支撑 + 养护质保

价格数据逐步记录区域、日期、来源和含税口径；未核实价格明确标记，不冒充权威市场价格。

## 🖼️ 图片本地化

正式版不依赖第三方网站图片热链。

- 图片统一进入 `public/assets/`
- 图片登记来源、许可、对应条目、图片类型和审核状态
- 不使用带第三方水印的图片，也不通过去除第三方水印重新利用
- 优先使用自有、明确授权、公共领域或许可允许再发布的素材
- 无合适授权照片时，可制作符合真实物种/材质特征的原创示意图，并明确标识
- 禁止通用图、重复图或 fallback 图片冒充具体植物和材料
- 乔木主图优先使用整株立面图，能够识别树形、冠幅、分枝和主干

## 💰 BOQ 与成果

- 业主汇报视图
- 施工算量视图
- 卡片价格与 BOQ 同源计算
- 主材/苗木价格穿透调整
- 本地多方案保存与比较
- CSV / Excel 清单输出
- 打印与汇报输出

## 📱 双端适配标准

正式验收同时覆盖桌面端和移动端。

- **视口**：390 / 768 / 1024 / 1440 / 1920 px
- **浏览器缩放**：50% / 75% / 100% / 125% / 150%
- 检查图片和卡片流式缩放、横向溢出、移动端安全区、选品抽屉以及悬浮预算栏遮挡

## 🛠️ 当前 `main` 基础能力

- 庭院总面积输入
- 绿化 / 铺装 / 水景及构筑物比例计算
- 苗木数量粗估
- 铺装材料数量与损耗估算
- 可编辑造价清单
- 预备费与税率计算
- CSV 导出
- 本地浏览器保存
- 打印与深色模式
