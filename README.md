## 项目简介

**庭院设计百宝箱**不是单纯的面积计算器。项目目标是把庭院方案阶段常见的空间规划、植物选品、硬景材料、构造做法与工程造价放进同一套交互流程中，让设计选择能够继续落到工程量和预算结果。

当前仓库正在进行专业版重构。重构工作位于 `rebuild/professional-toolbox` 分支，完成数据核验、自动测试与双端适配后再合并至 `main`。

> 当前 `main` 为可运行基础版本；专业植物库、硬景构造库、图片本地化和可追溯造价体系正在重构中。README 不以未完成能力冒充已交付功能。

## 🧭 专业版规划

### 1. 项目与场地条件

- 城市 / 区域与气候区
- 庭院面积、朝向与日照
- 预算档位与设计风格
- 毛坯新院 / 老院翻新
- 大乔木进场与吊装条件

### 2. 动态空间配比

绿化、硬质铺装、水景及构筑物支持独立开关与动态调整，并保证总面积闭合。方案面积变化将继续传递到材料、植物和 BOQ 工程量。

### 3. 专业植物选品

专业版采用“主画布 + 选品抽屉”结构。主画布只展示当前方案已经选定的植物，候选植物进入专业选品界面筛选。

筛选维度包括：

- **植物分类**：常绿乔木、落叶乔木、庭院观果树、灌木与球类、花境、观赏草、竹类、藤本、水生湿生、草坪地被、阴生蕨类与苔藓等
- **观赏属性**：观花、观叶、观果、观姿观干、芳香、综合
- **季相条件**：春、夏、秋、冬以及具体月份数据
- **生态条件**：日照、水湿、耐寒、耐热等

每条正式植物数据将关联中文名、拉丁学名、工程规格、建议密度、季相信息、价格构成以及经过审核的本地图片。

### 4. 硬景材料与工程构造

计划覆盖天然石材、景观砖、透水材料、木竹与合成材料、生态铺装、金属收边、排水、墙面饰面以及庭院构筑物等类别。

材料条目将逐步具备：

- 规格与工艺
- 本地实景图
- 损耗率
- 构造断面
- 主材 / 辅材 / 人工 / 机械拆解
- BOQ 联动

### 5. 景观小品与水系

廊架、景墙、景观置石、庭院鱼池及过滤系统等作为独立工程模块选配，并与规格、工法和造价清单关联。

### 6. 可追溯造价体系

专业版造价目标不是给出一个无法解释的“网络参考价”，而是让综合单价可以拆解和调整：

**硬景：** 主材 + 基层/辅材 + 人工 + 机械 + 物流 + 损耗 + 措施

**苗木：** 苗木采购 + 土球包装 + 运输 + 种植土改良 + 人工/吊装 + 支撑 + 养护质保

价格数据将记录区域、日期、来源及含税口径。未核实数据会明确标识，不作为权威市场价格展示。

## 🖼️ 图片本地化原则

正式版本不依赖第三方网站图片热链。

- 图片统一进入 `public/assets/`
- 建立图片来源、许可、对应条目、图片类型和审核状态清单
- 不使用带第三方水印的图片，也不通过去除第三方水印重新利用
- 优先使用自有、明确授权、公共领域或许可允许再发布的素材
- 无合适授权照片时，可制作符合真实物种 / 材质特征的原创示意图，并明确标识
- 禁止用通用绿植、树叶、石材或其他 fallback 图片冒充具体条目
- 乔木主图优先采用整株立面图，能够识别树形、冠幅、分枝和主干

仓库已经加入图片资产审计机制，用于检查远程图片、缺图、重复图片和未审核素材。

## 💰 BOQ 与成果输出

专业版规划提供：

- 业主汇报视图
- 施工算量视图
- 卡片价格与 BOQ 同源计算
- 主材 / 苗木单价穿透调整
- 本地多方案保存与比较
- CSV / Excel 清单输出
- 打印 / 汇报输出

## 📱 响应式标准

桌面端与移动端都属于正式验收范围，而不是后期补丁。

目标视口：`390 / 768 / 1024 / 1440 / 1920 px`

浏览器缩放测试：`50% / 75% / 100% / 125% / 150%`

重点检查图片与卡片流式缩放、横向溢出、移动端安全区、弹窗/抽屉操作以及预算栏遮挡。

## 🛠️ 当前可运行基础版

当前 `main` 已具备以下基础能力：

- 庭院总面积输入

- 铺装材料数量与损耗估算
- 可编辑造价清单
- 预备费与税率计算
- CSV 导出
- 本地浏览器保存
- 打印与深色模式
